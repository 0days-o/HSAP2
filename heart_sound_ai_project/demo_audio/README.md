# Included audio demonstration files

This folder contains two **synthetic PCG-like sound effects** generated by the project itself:

- `synthetic_steady_timing_demo.wav`
- `synthetic_variable_timing_demo.wav`

They are included so you can immediately test WAV loading, waveform/spectrogram plotting, USB playback, speaker playback, and the microphone recording chain without waiting for the PhysioNet download.

**They are not real heart recordings, are not labeled normal/abnormal, and must not be used to train or evaluate the neural network.** They do not represent any person's health or any actual cardiac condition. For model training and scientific evaluation, use the separately downloaded, attributed PhysioNet/CinC Challenge 2016 dataset.
