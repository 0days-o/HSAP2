# Dataset folder

Menu option 1 downloads and extracts the official PhysioNet/CinC Challenge 2016 training archive to `data/physionet2016/`.

The archive is not bundled into this project ZIP. The project ZIP does include two synthetic WAV examples in `demo_audio/` for quick signal-pipeline tests; those are not real heart recordings and must not be used for classifier training or evaluation.

Official source and license: https://physionet.org/content/challenge-2016/1.0.0/
